Mandate is a strategy marketplace for tokenized equities where the
  execution is depth-proven and the track record is computed rather than claimed.

  
The problem. Copy trading runs on numbers you have to
  take someone's word for. The platform custodies your money, the star trader reports their
  own returns. You find out afterwards.

  
The fix. The strategy is a hash. The follower keeps
  their own wallet under revocable delegation. Every fill is a public log. Returns are
  derived from those logs, so a strategist cannot inflate a number that anyone can recompute.

  
The part nobody handles. Tokenized equity liquidity on
  Base is fragmented and salted with pools that quote a price and hold nothing. Routing into
  one is how a follower loses money on the way in. Mandate classifies every pool and refuses
  rather than filling badly.

  
Verify any of this yourself

  
git clone the repo, then:

  python3 scripts/verify_addresses.py    every address read off Base, live
  python3 scripts/scan_market.py         the pool classification above
  python3 -m unittest discover -s tests  the accounting and guard rules

No API key is needed. Every number on this page comes from public Base state.
